# Telegram Bot для проверки подписки на канал

Бот пускает писать в группу только подписчиков канала.

## 🚀 Возможности

- ✅ Проверка подписки при вступлении в группу и при каждом сообщении
- 🔇 Неподписанный пишет → сообщение удаляется, мут на 60 секунд (снимает сам Telegram через `until_date`, переживает перезапуск бота)
- 👁️ Подсказка с кнопками — ephemeral-сообщение, видно только нарушителю (если не доставилось — публичное, удаляется через 60 сек)
- 🔘 «✅ Men obuna bo'ldim» — проверяет подписку и снимает мут, выставленный ботом (ручные муты админов не трогает)
- 📝 Заявки на вступление: подписчиков одобряет, остальным пишет инструкцию в личку и отклоняет
- 📤 Пересылает новые посты канала в группу (альбомы — одним сообщением)
- 🗑️ Удаляет сервисные сообщения о входе/выходе
- 🤖 Не трогает админов, анонимных админов и автофорварды постов канала

## 📋 Требования

- Python 3.10+
- aiogram 3.31+ (Bot API 10.3 — нужен для ephemeral-сообщений)

## ⚙️ Установка

```bash
pip install -r requirements.txt
```

Файл `.env`:
```env
TOKEN=your_bot_token_here
CHANNEL_ID=@your_channel_username_or_id
GROUP_ID=your_group_id_here
CHANNEL_LINK=https://t.me/your_channel_username
```

```bash
python main.py
```

### Переменные окружения

- `TOKEN` — токен бота от @BotFather
- `CHANNEL_ID` — username или ID канала (`@channel_name` или `-1001234567890`)
- `GROUP_ID` — ID группы; если не задан, бот работает во всех группах
- `CHANNEL_LINK` — ссылка на канал. **Обязательна, если `CHANNEL_ID` числовой**, иначе кнопки «Obuna bo'lish» не будет

### Права бота

- Администратор **канала** — без этого Telegram не отдаёт статус подписки
- Администратор **группы** (супергруппы) с правами: удаление сообщений, ограничение участников, приглашение пользователей (для заявок на вступление)

## 📱 Команды

- `/start` — информация о боте (в личке)
- `/check` — проверить свою подписку (в личке)
- `/id` — ID чата (в группе, только админам)

## 🧪 Проверка

```bash
python test_main.py
```

## 🚨 Устранение неполадок

- **«Не удалось проверить подписку … (бот админ в канале?)»** — бот не админ канала. В этом случае бот пропускает пользователей, а не мутит всю группу.
- **«chat not found»** — проверьте `CHANNEL_ID` и `GROUP_ID`, бот должен быть добавлен в канал и группу.
- **Flood control (429)** — бот сам ждёт `retry_after` и повторяет отправку.
