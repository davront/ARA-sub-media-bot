# Telegram Bot для проверки подписки на канал

Бот автоматически проверяет подписку пользователей на канал перед доступом к группе.

## 🚀 Возможности

- ✅ Автоматическая проверка подписки при вступлении в группу
- 🔇 Автоматическое мутирование неподписанных пользователей
- 📺 Кнопка-ссылка на канал для подписки
- 🔘 Кнопка подтверждения подписки
- ⏰ Автоматические напоминания каждые 2, 5 и 10 минут
- 🔄 Автопроверка подписки каждые 30 секунд
- 📊 Ежедневная проверка всех участников в 9:00 утра
- 📈 Отчеты владельцу канала о неподписанных пользователях
- 🔧 Команда принудительной проверки `/force_check`

## 📋 Требования

- Python 3.8+
- aiogram 3.x
- python-dotenv

## ⚙️ Установка

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/your-username/your-repo.git
cd your-repo
```

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Создайте файл `.env`:**
```env
# Bot configuration
TOKEN=your_bot_token_here
CHANNEL_ID=@your_channel_username_or_id
GROUP_ID=your_group_id_here
CHANNEL_LINK=https://t.me/your_channel_username

# Channel owner ID (optional - bot will try to auto-detect if not set)
OWNER_ID=your_telegram_user_id_here
```

4. **Запустите бота:**
```bash
python main.py
```

## 🔧 Настройка

### Переменные окружения

- `TOKEN` - токен вашего бота от @BotFather
- `CHANNEL_ID` - ID или username канала (например: @channel_name или -1001234567890)
- `GROUP_ID` - ID группы, где работает бот
- `CHANNEL_LINK` - прямая ссылка на канал
- `OWNER_ID` - ваш Telegram ID (для получения отчетов)

### Права бота

Бот должен быть:
- ✅ Администратором группы
- ✅ Иметь права на ограничение пользователей
- ✅ Участником канала (для проверки подписки)

## 📱 Команды

- `/start` - информация о боте
- `/check` - проверить статус подписки (только в личке)
- `/id` - получить ID чата (только для админов группы)
- `/force_check` - принудительная проверка всех участников (только в личке)

## 🕐 Расписание

- **Ежедневная проверка:** каждый день в 9:00 утра
- **Напоминания:** через 2, 5 и 10 минут после мутирования
- **Автопроверка:** каждые 30 секунд в течение 5 минут

## 📊 Отчеты

После ежедневной проверки бот отправляет отчет владельцу канала с информацией о:
- Количестве проверенных пользователей
- Новых замьюченных пользователях
- Уже замьюченных пользователях
- Списке неподписанных пользователей

**Примечание:** Ежедневная проверка работает следующим образом:
- Проверяет администраторов группы (кроме владельца)
- Отправляет общее напоминание в группу о необходимости подписки
- Обычные участники проверяются индивидуально при вступлении или активности
- Telegram API не предоставляет прямой доступ к полному списку участников группы для безопасности

## 🎯 Как работает

1. **Новый пользователь вступает в группу**
2. **Бот проверяет подписку на канал**
3. **Если не подписан:**
   - Пользователь мутируется
   - Отправляется сообщение с инструкцией
   - Создаются кнопки для подписки
   - Запускаются напоминания и автопроверка
4. **Если подписан:**
   - Доступ разрешен
   - Пользователь может писать сообщения

## 🚨 Устранение неполадок

### "chat not found"
- Проверьте правильность `CHANNEL_ID` и `GROUP_ID`
- Убедитесь, что бот добавлен в канал и группу

### "can't remove chat owner"
- Это нормально - владелец группы не может быть ограничен

### "user is an administrator"
- Администраторы группы пропускаются при проверке
