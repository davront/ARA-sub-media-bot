# Telegram Subscription Bot

Бот для проверки подписки на канал перед отправкой сообщений в группе.

## Функции
- Проверяет подписку на канал при вступлении в группу
- Мутит неподписанных пользователей
- Показывает кнопку "✅ Obuna bo'ldim" для подтверждения подписки
- Автоматически снимает мут после подтверждения подписки
- Удаляет сообщения через 10 секунд

## Установка

### Локально
```bash
python -m venv .venv
. .venv/Scripts/activate  # Windows
pip install -r requirements.txt
```

### Переменные окружения (.env)
```env
TOKEN=ваш_токен_бота
CHANNEL_ID=@ваш_канал
GROUP_ID=-1002738133830
CHANNEL_LINK=https://t.me/ваш_канал
```

## Деплой на Render.com

1. Создайте Web Service на [Render.com](https://render.com)
2. Подключите GitHub репозиторий
3. Добавьте переменные окружения:
   - `TOKEN` = токен бота из @BotFather
   - `CHANNEL_ID` = @ваш_канал или -100...
   - `GROUP_ID` = -1002738133830
   - `CHANNEL_LINK` = https://t.me/ваш_канал
4. Build Command: `pip install -r requirements.txt`
5. Start Command: `python main.py`

## Команды бота
- `/start` - приветствие
- `/check` - проверка подписки
- `/id` - получить ID группы (только для админов)

## Права бота
- В группе: ограничивать участников, удалять сообщения
- В канале: просмотр участников (для приватного - админ)
