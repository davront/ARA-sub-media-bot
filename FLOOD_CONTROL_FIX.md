# Исправление проблемы Flood Control в Telegram Bot

## Проблема
Бот превышает лимиты Telegram Bot API на отправку сообщений, что приводит к ошибкам:
```
Too Many Requests: retry after 5
Flood control exceeded on method 'SendMessage'
```

## Решение
Добавлены следующие улучшения:

### 1. Безопасные функции отправки сообщений
- `safe_send_message()` - безопасная отправка сообщений с повторными попытками
- `safe_reply_message()` - безопасный ответ на сообщения с повторными попытками

### 2. Настройки Flood Control
```python
MESSAGE_DELAY = 0.5      # Задержка между сообщениями (секунды)
MAX_RETRIES = 3          # Максимальное количество попыток
RETRY_DELAY = 5          # Задержка перед повторной попыткой (секунды)
```

### 3. Автоматические задержки
- Задержка 1 секунда между проверками администраторов
- Задержка 2 секунды после отправки уведомлений
- Задержка 0.5 секунды между повторными попытками

### 4. Умная обработка ошибок
- Автоматическое извлечение времени ожидания из ошибки Telegram
- Fallback на отправку новых сообщений при неудачных ответах
- Логирование всех попыток и ошибок

## Использование
Все функции отправки сообщений теперь используют безопасные методы:
- `bot.send_message()` заменен на `safe_send_message()`
- `message.reply()` заменен на `safe_reply_message()`
- Добавлены проверки успешности отправки

## Рекомендации
1. **Не уменьшайте задержки** - это может привести к повторным ошибкам
2. **Мониторьте логи** - следите за предупреждениями о flood control
3. **Настройте GROUP_ID** - убедитесь, что бот работает только в нужной группе
4. **Используйте переменные окружения** - настройте TOKEN, CHANNEL_ID, GROUP_ID

## Переменные окружения
```bash
TOKEN=your_bot_token
CHANNEL_ID=@your_channel or -1001234567890
GROUP_ID=-1001234567890
CHANNEL_LINK=https://t.me/your_channel
```

## Тестирование
После внесения изменений:
1. Перезапустите бота
2. Проверьте логи на наличие ошибок flood control
3. Протестируйте добавление новых участников
4. Убедитесь, что напоминания отправляются корректно
